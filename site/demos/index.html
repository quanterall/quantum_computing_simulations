// Demo suite v2.5 · on the BEAM

Running quantum circuits
on the Erlang VM

Ten live demonstrations — four algorithms and protocols, one quantum ML circuit and five error-correcting codes — executed in real time on the BEAM by QxSim, a pure-Elixir state-vector simulator inside this service. The demos began on qx, Craig Richards' Elixir simulator (Apache-2.0, version 0.5.1), which we credit; QxSim is a separate implementation on Erlang tuples, and a comparison with every qx release (all built on Nx) found no shared code. Every result is computed fresh on each run.

01
Bell State Entanglement
Protocol

Creates the maximally entangled Bell state |Φ⁺⟩ = (|00⟩+|11⟩)/√2 using a Hadamard and a CNOT gate. Measurement outcomes should be perfectly correlated.

/quantum/teleport
02
Quantum Teleportation
Protocol

Teleports a random state ψ (θ, φ drawn from the seed) from Alice (q0) to Bob (q2) through a shared Bell pair: Alice's Bell measurement, then Bob's corrections X and Z as controlled gates (deferred measurement). Bob then undoes the preparation of ψ: if ψ arrived intact, his qubit — the leftmost bit — reads 0 in every shot, while Alice's two bits are uniformly random. A copied bit would not pass: ψ carries a phase and a superposition.

/quantum/grover
03
Grover's Search
Algorithm

Grover's search. Run: two qubits, the oracle marking |11⟩, one iteration finds it every time. Search: 2 to 10 qubits and any marked state (or a random one): the marked state's probability after every iteration, exact from the state vector beside theory, and shots sampled at the optimum, about (π/4)√N iterations — against N/2 tries on average for a classical search.

/quantum/shor15
05
Shor's Algorithm (N=15, compiled)
Algorithm

Shor's algorithm for N = 15, compiled for a = 7: three counting qubits and four work qubits, controlled ×7 and ×4 mod 15, the inverse QFT, then the classical step. 7⁴ ≡ 1 (mod 15), so the period is built into this circuit: it shows the structure, not a speedup. k = 2 and 6 give the period 4 and 3 × 5 directly (about half the shots); k = 4 gives it after checking multiples; k = 0 gives nothing. The general algorithm — N = 15 or 21, any a, 2n counting qubits, controlled multiplication by a^(2^j) mod N, continued fractions, nothing about the period put in — is /quantum/shor?N=21&a=2, and a card on the homepage.

/quantum/qec/bitflip
06
3-Qubit Bit-Flip Code
QEC

Logical |0⟩ on three qubits; an X error on the chosen qubit; two ancillas measure the parities Z₀Z₁ and Z₁Z₂, and a majority vote corrects a single bit flip. Gates and measurements are noiseless.

/quantum/qec/phaseflip
07
3-Qubit Phase-Flip Code
QEC

Logical |0⟩ encoded as |+++⟩, a Z error on the chosen qubit. The checks X₀X₁ and X₁X₂ are measured on one ancilla, reset after each; the syndrome names the qubit and a Z gate corrects it. The data are read out in the X basis.

/quantum/qec/shor9
08
Shor's 9-Qubit Code
QEC

Shor's code: a phase-flip code over three bit-flip codes, logical |0⟩. The injected error is Y — a bit flip and a phase flip at once. Six Z checks (two per block) find the bit flip, two X checks across blocks find the phase flip, all on one reused ancilla; the decoder applies X and Z. Shown: the logical qubit (parity of the nine X-basis outcomes), 0 or 1, with the error left in and corrected.

/quantum/qec/steane7
09
Steane [[7,1,3]] Code
QEC · CSS

Steane's [[7,1,3]] code, built from the Hamming code, logical |0⟩. The injected error is Y. Three Z checks and three X checks on the same supports, on one reused ancilla: each syndrome, read in binary, is the error's position. Shown: the logical qubit (parity of the seven outcomes), 0 or 1, with the error left in and corrected.

/quantum/qec/surface3
10
Distance-3 Surface Code Patch
QEC · Surface, full

The full rotated surface code of distance 3: nine data qubits on a 3×3 grid and all eight stabilizers — X on {0,1,3,4} {4,5,7,8} {1,2} {6,7}, Z on {1,2,4,5} {3,4,6,7} {0,3} {5,8} — measured on one reused ancilla. Logical |0⟩ is made by measurement (a first round is the reference), the injected error is Y, and a lookup decoder applies X and Z. Shown: the logical qubit Z0Z1Z2, with the error left in and corrected. Under gate-level noise, with 17 to 97 qubits, the code runs on our stabilizer simulator (homepage, Results).
